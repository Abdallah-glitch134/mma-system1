نظام MMA — المشروع S V7

هذه النسخة عربية بالكامل افتراضياً، وتحتوي على زر «تثبيت التطبيق» عندما يسمح المتصفح بذلك.

تثبيت على Android:
1) ارفع مجلد mma_system على استضافة HTTPS (مثل GitHub Pages أو Cloudflare Pages أو Firebase Hosting).
2) افتح رابط الموقع من Chrome على الهاتف.
3) اضغط «تثبيت التطبيق» من داخل البرنامج، أو من قائمة Chrome اختر «إضافة إلى الشاشة الرئيسية / تثبيت التطبيق».
4) سيظهر البرنامج كتطبيق مستقل على الشاشة الرئيسية.

مهم: PWA يحتاج HTTPS عند استخدام الاستضافة. localhost مستثنى أثناء التطوير.

تحليل الفيديو:
- شغّل backend الموجود في مجلد backend.
- ضع OPENAI_API_KEY في ملف البيئة على الخادم فقط، وليس داخل index.html.
- التحليل يعيد ملاحظات تقنية باللغة العربية، تمارين تصحيح، وخطة 7 أيام.
- التحليل ليس بديلاً عن مدرب يشاهدك مباشرة، ولا يشخّص الإصابات.
